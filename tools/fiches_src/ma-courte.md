Les 4 calculs qui tombent : **coût total et unitaire, BEP, seuil d'indifférence, full costing par centres**. Chaque résultat demande une phrase d'interprétation.

## Formules

| Quoi | Formule |
| --- | --- |
| Coût total | TC = FC + Q × uVC |
| Coût unitaire | TC / Q (baisse quand Q monte) |
| High-low | v = Δcoûts / Δunités, puis F = TC − v × Q |
| Contribution margin | CM = TO − VC = Q × uCM, avec uCM = SP − uVC |
| Résultat | PM = CM − FC |
| CM ratio | CM / TO = 1 − uVC / SP |
| BEP en unités | Q\* = FC / uCM, **arrondi à l'unité supérieure** |
| BEP en CA | FC / CM ratio = Q\* × SP |
| Date du BEP | Q\* / ventes annuelles × 12 mois |
| Target profit | Q = (FC + profit visé) / uCM |
| Margin of safety | Ventes − ventes au BEP |
| Seuil d'indifférence | Q = (FC1 − FC2) / (uVC2 − uVC1) |
| Full cost | DC + IC alloués, PM/u = SP − full cost/u = MDC/u − IC/u |
| Unit cost driver | uCD = IC du centre / total des unités de CD |
| Product cost en absorption | DM + DL + Var MOH + Fixed MOH / unités **produites** |
| Product cost en variable costing | DM + DL + Var MOH |

## Définitions à savoir

- **3 types d'entreprises** : service (pas de stock), merchandising (1 stock), manufacturing (3 stocks : raw materials, WIP, finished goods).
- **3 responsabilités du manager** : planning (le budget), directing, controlling.
- **Financial accounting** : externe, passé, normes obligatoires. **Management accounting** : interne, futur, pas de normes, tourné vers la décision.
- **Value chain** : R&amp;D, design, purchases/production, marketing, distribution, customer service.
- **Cost object** : tout ce dont on veut connaître le coût (produit, client, projet, département).
- **Direct cost** : rattachable directement (traced). **Indirect cost** : à répartir (allocated).
- **Variable cost** : total proportionnel au volume, constant par unité. **Fixed cost** : total constant, baisse par unité. **Mixed cost** : y = vx + F.
- **Inventoriable cost** : DM + DL + MOH, stocké puis passé en COGS à la vente. **Period cost** : tout le reste (R&amp;D, vente, admin, distribution).
- **MOH** : indirect materials, indirect labor, autres coûts d'usine.
- **Absorption costing** : fixed MOH stocké, solde = gross margin, obligatoire en externe. **Variable costing** : fixed MOH en charge de la période, solde = contribution margin, outil de décision.
- Production &gt; ventes : résultat absorption &gt; résultat variable (l'écart vaut fixed MOH/u × variation du stock).
- **Cost driver** : variable corrélée à la consommation d'IC, de préférence physique.
- **Homogène** : les ressources sont consommées dans des proportions stables, donc le choix de CD ne change rien. **Hétérogène** : le résultat dépend du CD, et le vrai coût n'existe pas.
- **Cross-subsidization** : un produit paie les IC d'un autre.
- **3 méthodes d'allocation** : simple allocation (un CD), organisational cost centres (auxiliaires puis principaux, deux étapes), ABC (ressources, puis activités, puis produits).
- **ABC en 4 étapes** : identifier les activités, leur affecter les IC, choisir les CD, répartir sur les produits.

## Arbre de décision « abandonner un produit »

1. PM &gt; 0 : on garde.
2. PM &lt; 0 mais MDC &gt; 0 : on **garde**, le problème vient de l'allocation des IC.
3. MDC &lt; 0 mais CM &gt; 0 : on **garde**, on agit sur le prix, le volume et les coûts directs.
4. CM &lt; 0 : on **abandonne**.
